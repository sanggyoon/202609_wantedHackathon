# 실제 사건 링크 연결 (2026-09-16)

## 구현 범위

- 홈의 시작하기 → POST /api/cases → /case/[token] 이동.
- API 어댑터: frontend/src/lib/api/cases.ts. 생성/조회 요청, 런타임 응답 검증,
  15초 제한, no-store, 원문 서버 오류를 노출하지 않는 오류 변환.
- 로컬 Next 개발 서버에서 /api/cases 경로를 백엔드로 전달.
- 조회 결과의 viewer_role·status·available_actions로 작성 가능 여부 결정.
- DRAFT의 A는 기존 AI 대화 → 공유 항목 선택 → 초안 검토까지 가능.
  statement 저장 API가 없으므로 접수 버튼은 비활성화한다.
- DRAFT의 B는 내용 없이 작성 대기 안내. 완료/대기 사건은 저장된 카드·리포트·사과만 표시.
  새로운 AI 리포트를 임의로 생성하지 않는다.
- 저장된 A 카드가 존재하고 DRAFT가 아닐 때 작성자에게 링크 복사/공유 제공.
  클립보드 실패 시 직접 선택 가능한 URL, 공유 미지원 시 복사로 대체.
- 404/410은 내용을 제거하고 안내. 일시적인 재조회 실패는 기존 입력을 유지.
- 최초 진입, 포커스 복귀, pageshow, 수동 버튼으로 조회. 자동 폴링 없음.
- 서버 expires_at 도달 시 표시 내용을 제거한다. 만료 판정의 최종 권위는 서버다.
- /wireframe은 기존 가상 사건 체험으로 유지한다. 실제 작성은 /에서 시작한다.

## 작성 권한 보관

- 사건별 writer_token과 expires_at만 sessionStorage에 보관한다.
- 같은 탭 새로고침 시 유지된다. 다른 탭/기기·탭 종료 후 권한 복구는 보장하지 않는다.
  브라우저가 복제 탭에 sessionStorage를 복사할 수 있으므로 사용자 신원 인증 수단은 아니다.
- 작성 권한 검증은 서버의 X-Writer-Token 검사로만 한다.
- public_token만 URL에 넣고 writer_token은 요청 헤더에만 사용한다.
- 대화·카드 초안·사과 원문은 브라우저 저장소에 저장하지 않는다.
- 저장소를 사용할 수 없으면 생성 요청 전에 안내한다. 생성 후 보관 실패 시
  같은 화면에서 발급 응답을 재사용하여 사건을 중복 생성하지 않는다.
- POST는 자동 재시도하지 않는다. 네트워크 실패 시 서버에 빈 사건이 생성됐을 수 있다.
  서버의 생성 멱등성 계약이 없어 새 요청으로 생기는 빈 사건까지 막지는 못한다.
- 사건 페이지의 referrer 정책은 no-referrer. 접근 로그의 토큰 마스킹은 별도 배포 작업이다.

## 남은 연결

statement(A/B), response-type, apology 쓰기 API는 현재 main에 없다.
따라서 새 사건으로 실제 고소장 저장 → 상대에게 전달 → 답변 제출까지 완료할 수 없다.
해당 API를 연결할 때 서버 성공 응답 이후에만 다음 단계로 전환해야 한다.
배포 DB·AI 환경변수, DB 마이그레이션, 로그 마스킹도 별도 확인 대상이다.

## 검증 및 실행

- frontend에서 npm test: API/권한 저장소 회귀 테스트 16개 (fetch·storage 대체).
- npm run lint, npm run build 통과.
- 브라우저에서 홈의 시작하기 → 저장 서버 미설정(503) 안내 확인.
- 현재 로컬 설정에 DATABASE_URL이 없어 실제 DB 생성·조회 성공 검증은 미수행.
  토큰/DB 비밀 값은 테스트 로그에 출력하지 않는다.
- backend/.env에 개발 DB의 DATABASE_URL을 설정하고 백엔드를 재시작해야 한다.
  브라우저용 NEXT_PUBLIC_ 변수에 DB 주소나 AI 키를 넣지 않는다.
- 프론트 npm run dev, 백엔드 uv run uvicorn app.main:app --reload --port 8000.
  http://localhost:3000 에서 시작한다.

실DB 연결 후 추가 확인: 시작하기 연속 클릭 시 한 사건만 생성, 새로고침 시 A 유지,
권한 없는 별도 브라우저에서 DRAFT 내용 비노출, 저장된 사건 조회/링크 복사,
만료 사건 410 및 내용 비노출. 운영 DB에 시험 내용을 저장하지 않는다.
