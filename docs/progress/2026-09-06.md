## CI/CD

- `.github/workflows/ci.yml` — PR 시 frontend `npm ci && npm run lint && npm run build`
- `.github/workflows/deploy.yml` — `main` merge 시:
  1. frontend 이미지 빌드 → GHCR push (`ghcr.io/sanggyoon/wanted-frontend`, `:latest` + `:<short-sha>`)
  2. GitHub Actions 러너가 Tailscale ephemeral node로 tailnet 접속 (`tailscale/github-action`, `tag:ci`)
  3. SSH로 서버 접속 → `docker compose pull && up -d` (GHCR pull 인증은 워크플로우의 `GITHUB_TOKEN` 사용, 별도 PAT 불필요)
- 라우터 22번 포트를 열지 않기 위해 SSH 경로를 Tailscale 경유로 설계 (기존 Tailscale-only 선호 패턴과 일치)
- 서버에 배포 전용 SSH 키페어(`gha_deploy_wantedhackathon`) 생성, `authorized_keys`에 공개키 등록
- GitHub repo에 Secrets 5종 등록 완료: `SSH_HOST`, `SSH_USER`, `SSH_PRIVATE_KEY`, `TS_OAUTH_CLIENT_ID`, `TS_OAUTH_CLIENT_SECRET`
- Tailscale ACL에 `tag:ci` 정의 + 해당 태그로 스코프(`auth_keys` write)를 가진 OAuth client 발급
