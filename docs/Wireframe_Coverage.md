## 체험 가능한 동작

- A/B의 세 가지 필수 답변 입력 → 미리보기 → 수정 → 확정
- B의 사과·맞고소 분기
- 사과문 원문과 선택 입력을 결과에 반영
- 요약·상세 펼치기와 화면 선택
- 최대 768px 컨테이너, 768px 이상 2열 리포트

## 화면 초안과 실제 기능의 차이

- `/wireframe`에서도 AI 대화·중재 리포트·죄명/요약/도입문 생성은 실제 API를 호출한다.
  가상 사건 데이터로 시작할 뿐이다.
- `/wireframe`의 링크 발급·복사·공유 버튼만 비활성 자리표시자다. 실제 발급·복사·공유는
  홈(`/`)에서 시작하는 `/case/[token]` 흐름에서 동작한다.
- 저장·7일 자동 만료·작성 권한·중복 제출 방지는 실제 흐름에서 구현됐다. **위험 내용 감지는
  여전히 미구현**이며 휴정 안내 화면은 개발용 네비게이터에서만 볼 수 있다.
- 종결 요약의 "밤톨의 추천"과 A/B 카드 색 구분은 아직 없다.
- 오류 재시도는 화면 전환 체험이며 네트워크 실패 복구를 검증하지 않는다.
- 호칭·날짜·장소·실제 발언·벌칙·장난 수위는 PRD의 선택 정보다. 현재 자유 대화에 적을 수 있으나 별도 선택 입력 UI와 AI 추출은 없다.
- 사과문 교정·링크 폐기·알림·초안 복구는 미정 정책이므로 확정 기능으로 추가하지 않는다.
- 제품 화면 목록은 모두 포함하지만 PRD의 전체 기능 요구사항이 구현 완료됐다는 뜻은 아니다.
