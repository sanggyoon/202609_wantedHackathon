# PRD 화면 반영 점검표

> 2026-09-10 · API 없는 화면 초안 · 검토 경로 `/wireframe`

처음 진입하면 시작 화면이 보인다. 작성 시작 버튼으로 A 흐름을 진행하고, 공유·대기에서 상대 화면 체험으로 B 흐름을 진행한다. 상단 선택기는 모든 화면을 직접 검토하는 도구다.

| --- | --- | --- |

| 9.2 | A 대화 | 단일 질문, 입력, 답변 수정, 현재 수집 내용, 이탈 시 소실 안내 |
| 9.3 | A 미리보기, 공유·대기 | 카드 미리보기, 내용 수정, 확정, 링크·복사·공유 버튼 자리 |

| 디자인 시스템 | 로딩 | 스켈레톤 화면 예시 |

## 체험 가능한 동작

- A/B의 세 가지 필수 답변 입력 → 미리보기 → 수정 → 확정
- B의 사과·맞고소 분기
- 사과문 원문과 선택 입력을 결과에 반영
- 요약·상세 펼치기와 화면 선택
- 최대 768px 컨테이너, 768px 이상 2열 리포트

## 화면 초안과 실제 기능의 차이

- AI 생성·중재는 미연결이다. 죄명은 예시이며 기대·해석 차이·중재·종결 요약은 영역만 제공한다.
- 실제 링크 발급·복사·공유 버튼은 비활성이다. 모든 체험은 `/wireframe`에서 진행한다.
- 저장·7일 자동 만료·작성 권한·중복 제출 방지·위험 감지는 미구현이다. 대응 화면만 있다.
- 오류 재시도는 화면 전환 체험이며 네트워크 실패 복구를 검증하지 않는다.
- 호칭·날짜·장소·실제 발언·벌칙·장난 수위는 PRD의 선택 정보다. 현재 자유 대화에 적을 수 있으나 별도 선택 입력 UI와 AI 추출은 없다.
- 사과문 교정·링크 폐기·알림·초안 복구는 미정 정책이므로 확정 기능으로 추가하지 않는다.
- 제품 화면 목록은 모두 포함하지만 PRD의 전체 기능 요구사항이 구현 완료됐다는 뜻은 아니다.
